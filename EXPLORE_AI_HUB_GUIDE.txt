1. WHAT IS "explore-ai-hub"? (THE BIG PICTURE)
--------------------------------------------------------------------------------
An Azure AI Multi-Service Account (resource kind: "AIServices", historically known 
as "Cognitive Services") is Microsoft Azure's consolidated umbrella for pre-trained 
enterprise machine learning APIs.

Instead of provisioning 5+ separate cloud resources (one for Vision, one for 
Speech, one for Translation, one for Document OCR, etc.), "explore-ai-hub" serves
as a SINGLE CORPORATE GATEWAY that gives your applications:
  - 1 unified HTTPS endpoint
  - 1 set of dual API keys (key1 / key2)
  - 1 consolidated monthly bill and budget item
  - 1 centralized Role-Based Access Control (RBAC) security boundary

3. THE 6 PILLARS INSIDE YOUR MULTI-SERVICE HUB
--------------------------------------------------------------------------------

[PILLAR 1: Azure AI Document Intelligence (Highest FDE Priority)]
* What It Does : Converts unstructured PDFs, scanned documents, and images
                 into structured JSON, markdown, and tables.
* Key Models   :
    - Layout       : Extracts text reading order, headers, tables, checkboxes,
                     and formatted Markdown (essential for RAG vector search).
    - Invoices     : Detects VendorName, TotalAmount, Tax, DueDate, and line items.
    - Receipts     : Extracts merchant, date, transaction subtotal, and tip.
    - Identity     : Parses passports, driver's licenses, and national ID cards.
* Web Studio   : https://documentintelligence.ai.azure.com

[PILLAR 2: Azure AI Language]
* What It Does : Natural language processing (NLP) on raw text.
* Key Models   :
    - PII Redaction: Automatically detects and masks credit card numbers, SSNs, 
                     emails, and addresses before logging customer transcripts.
    - NER          : Named Entity Recognition identifies people, places, and orgs.
    - Sentiment    : Analyzes positive, negative, and neutral emotional valence.
    - Summarization: Extractive and abstractive summarization of long docs.
* Web Studio   : https://language.cognitive.azure.com

[PILLAR 3: Azure AI Vision (Image Analysis 4.0)]
* What It Does : Visual scene understanding and optical character recognition.
* Key Models   :
    - Read (OCR)   : Extracts embedded text from photos, signs, and labels.
    - Captioning   : Generates complete human descriptions of uploaded scenes.
    - Object Detect: Draws bounding boxes around detected items and people.
    - Smart Crop   : Intelligently crops photos based on focal regions.
* Web Studio   : https://portal.vision.cognitive.services.azure.com

[PILLAR 4: Azure AI Speech]
* What It Does : Voice transcription, synthetic voices, and audio translation.
* Key Models   :
    - Speech-to-Text (STT) : Real-time streaming transcription (Whisper support).
    - Text-to-Speech (TTS) : 400+ neural voices with human inflection.
    - Voice Avatars        : Generates photorealistic video avatars speaking text.
* Web Studio   : https://speech.microsoft.com

[PILLAR 5: Azure AI Content Safety & Decision]
* What It Does : Guardrails and security filtering for Generative AI & LLMs.
* Key Models   :
    - Prompt Shield: Detects and blocks prompt injection and jailbreak attacks.
    - Moderation   : Scans text/images for hate speech, violence, and adult content.
* Web Studio   : https://contentsafety.cognitive.azure.com

[PILLAR 6: Metrics Advisor]
* What It Does : Automated time-series anomaly detection and diagnostic insights
                 for enterprise operational KPIs (e.g. tracking sales drop-offs).

4. ENTERPRISE AUTHENTICATION & ZERO-DOWNTIME KEY ROTATION
--------------------------------------------------------------------------------
Azure provides two API keys: "key1" and "key2".

HOW PRODUCTION ROTATION WORKS WITHOUT DOWNTIME:
1. Application initially points to "key1".
2. When rotating security credentials, configure the application to use "key2".
3. Verify that traffic continues uninterrupted.
4. Execute key regeneration on "key1":
     az cognitiveservices account keys regenerate `
         --name "explore-ai-hub" `
         --resource-group "rg-azure-explorer" `
         --key-name key1
5. Next cycle, repeat the process in reverse.

PASSWORDLESS ENTERPRISE IDENTITY (Entra ID / RBAC):
In high-security production deployments, hardcoded API keys are disabled.
Applications authenticate using Azure Managed Identity:
  - Role Assigned : "Cognitive Services User"
  - SDK Code      : DefaultAzureCredential()

    --name "explore-ai-hub" `

    --resource (az cognitiveservices account show --name "explore-ai-hub" --resource-group "rg-azure-explorer" --query "id" -o tsv) `
    --metric "TotalCalls" `
    --output table

7. SAMPLE TEST: CALLING THE LANGUAGE API VIA POWERSHELL
--------------------------------------------------------------------------------
$ENDPOINT = (az cognitiveservices account show --name "explore-ai-hub" --resource-group "rg-azure-explorer" --query "properties.endpoint" -o tsv)
$KEY = (az cognitiveservices account keys list --name "explore-ai-hub" --resource-group "rg-azure-explorer" --query "key1" -o tsv)

$payload = @{
    kind = "SentimentAnalysis"
    analysisInput = @{
        documents = @(
            @{ id = "1"; language = "en"; text = "Azure AI Services simplifies multi-modal enterprise workflows!" }
        )
    }
} | ConvertTo-Json -Depth 5

Invoke-RestMethod `
    -Uri "$($ENDPOINT)language/:analyze-text?api-version=2023-04-01" `
    -Method Post `
    -Headers @{ "Ocp-Apim-Subscription-Key" = $KEY; "Content-Type" = "application/json" } `
    -Body $payload | ConvertTo-Json -Depth 4
